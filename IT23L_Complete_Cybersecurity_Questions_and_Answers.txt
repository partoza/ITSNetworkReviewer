Question 1:
A healthcare provider uses an electronic health record (EHR) system. To protect Confidentiality, which of the following actions should be taken?
A) Implement checksums on all health records
B) Ensure the system is always online
C) Keep a daily backup of all patient data
D) Encrypt patient records and restrict access based on roles
CORRECT ANSWER: D

Question 2:

A) Availability
B) None of these
C) Integrity
D) Confidentiality
CORRECT ANSWER: D

C) Digital signatures
D) Firewalls
CORRECT ANSWER: A

A) Using a hash function to ensure data integrity
B) Regularly updating software to prevent system downtime
C) Implementing redundant systems to prevent data loss
D) Using encryption to protect sensitive data during transmission

Question 5:

D) System downtime due to hardware failure
